# 素材库 · 操作教程（照着点就行）

> 目标：**输入一句话，找到它是哪个主播、哪个视频、第几秒说的。**
>
> 全程只有一个概念要记住：**搜索查的是"索引"，不是你的视频文件。**
> 索引很小（几 MB），可以像文件一样发给别人。

---

## 情况一：同事给了你一个索引包（最常见）

只要 4 步：

**① 点页头右上角的「导入索引」**

**② 选中同事发来的 zip**（可以一次选多个，比如不同主播各一个）→ 确定

**③ 等 2~5 秒**，右侧「索引列表」里会自动出现新索引，例如：

```
影子       导入   69 视频 · 11353 句 · 19.1h     ← 类型标「导入」的就是别人分享的
录屏       本机  103 视频 · 17634 句 · 19.6h     ← 你自己扫的
```

> 不用刷新页面，列表会自己更新。

**④ 现在就能搜了**：在上面输入框里打字 → 点「检索」。

> 你的电脑上**不需要有这些视频文件**，照样能搜出"哪个视频有这句话"。

---

## 情况二：你要用自己的录屏建索引

**① 在「素材目录」里选你的录屏文件夹**
点「选择文件夹」，选到**主播文件夹的上一层**，例如 `E:\切片\录屏`。

**② 勾选「包含子文件夹」**（视频在主播子目录里，必须勾）

**③ 先点「试扫目录」**，看清楚工作量：

```
试扫完成：视频 515 个（已在索引 199 个 · 本次可新增 316 个）
  · 已有字幕 200 个 · 待识别 315 个 · 151.2 GB
```

**④ 决定「缺字幕自动语音识别」勾不勾**

| | 结果 |
|---|---|
| **不勾**（推荐第一次） | 只索引已有字幕的视频，**几分钟就能用** |
| **勾上** | 没字幕的也去识别，能搜到更多，但**很慢**（几百个视频可能跑几小时） |

**⑤ 点「建立/更新这个目录的索引」**

- 如果目录已经索引过，它会告诉你"无需重跑"，不会重复干活；
- 如果要跑很多语音识别，它会**先弹框问你**，让你决定是否继续。

**⑥ 等它跑完**（进度看页面下方的「素材库日志」），然后就能搜了。

---

## 怎么搜才搜得到

**✅ 搜 2~4 个字的片段，最好用**（下面数字取自一个 280 多个视频的真实库）

```
显瘦        ✅ 274 处
帽子        ✅ 515 处
巫师帽      ✅  12 处
```

**❌ 一整句话经常搜不到** —— 库里的句子是按**说话停顿**切开的，和你记忆里的整句对不上：

```
这个帽子版型很显瘦     ❌ 0 处        ← 记忆里的整句，库里没有这个连续片段
帽子 版型             ✅ 25 处        ← 改成"分词匹配"（用空格隔开），命中面更广
```

**记住这条就够了**：

- 搜不到 → **把词缩短**，或者**用空格把词拆开**（匹配方式选「分词匹配」）。
- 另外：**同义说法互相搜不到**。你说"显瘦"，视频里说的是"显身材"，就搜不出来——换几个说法试。

## 只想搜某个主播/某个索引

搜索框上方有个「**搜索范围**」下拉：

```
搜索范围  [全部索引 ▾]
           ├─ 全部索引
           ├─ 录屏        ← 点它就只在这个索引里搜
           ├─ jccc
           └─ Ayobe小贤
```

点一下某个索引 → **只搜它**；再点「全部索引」→ 恢复搜全部。

> 导入的索引多了以后建议先选范围，**搜得更快、结果更干净**。

---

## 结果怎么看，怎么用

一张卡片 = 一个视频：

```
影子 待确认_20260930_172358_01_1.mp4   录屏      命中 6 处  首次出现 10:06
┌──────────────────────────────────────────────────────┐
│ 10:06  ▶ 打开视频   📁 打开视频地址   ⧉ 复制时间点     │
│   10:06  因为显瘦 颜值可高。          ← 命中句已加粗    │
│   10:07  因为显瘦 它不显胖。                          │
└──────────────────────────────────────────────────────┘
```

| 你想做的事 | 点哪里 |
|---|---|
| 直接看这段视频 | **▶ 打开视频**（会用播放器打开，时间点已可复制，手动跳过去） |
| 找到这个视频文件 | **📁 打开视频地址**（在资源管理器里定位到文件） |
| 记下时间点 | **⧉ 复制时间点**；结果区右上「复制全部时间点」可一次全复制 |
| 卡片上有「**需下载**」 | 说明本机没这个视频 → **拿卡片上的文件名去网盘找** |

## 把索引分享给别人

1. 右侧「索引列表」里，找到要分享的那个索引；
2. 点它右边的「**导出**」→ 选保存位置；
3. 得到一个几 MB 的 zip（例如"影子"的索引约 **5 MB**）；
4. 发给同事，他按【情况一】导入即可。

> 一个索引一个包，**别人只要自己需要的那些**，不用一次拿全部。

## 常见问题（30 秒排查）

| 现象 | 怎么办 |
|---|---|
| **搜不到**我确定说过的话 | ① 先把搜索范围点回「全部索引」；② 把搜索词**缩短到 2~4 个字**；③ 确认这个目录建过索引（点「试扫目录」看"已在索引 N 个"）；④ 视频有没有字幕——没字幕的不会被索引 |
| 换了素材目录，搜不到新目录的东西 | 换目录**不会自动扫**，要点「建立/更新这个目录的索引」 |
| 导入后列表没变化 | 等 **2~5 秒**（界面自动同步）。一直没有就看页面下方「素材库日志」的报错 |
| 点导出报 `Method Not Allowed` | 页面是旧版 → **按 Ctrl+F5 强制刷新** |
| 索引在哪、会不会占很多空间 | `%APPDATA%\LiveClipper\material_library\material.sqlite3`，几百个视频也就几十 MB |
| **删除某个索引**会不会删我的视频 | **不会**。在索引卡片上点「删除」，只删这个索引的内容（文案/时间点），**视频和字幕文件都不动** |

---

## 一句话总结

**导入索引 → 搜短词 → 看卡片上的主播和文件名 → 要视频就去网盘下。**

需要更细的原理和边界说明，看同目录的《素材库使用说明》。
