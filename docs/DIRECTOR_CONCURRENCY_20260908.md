# 智能成片与混剪并行

用户选择：AI 分析并行，最终视频渲染排队。

## 实现

- 工作区独立接收任务：智能成片和混剪可各运行一个任务；混剪与批量混剪互斥。同一工作区的检查和创建在同一锁内完成，避免重复点击竞态。
- 正式导演的直接成片与预览转成片均通过共享渲染通道。等待时显示状态，可独立取消；失败也会释放通道。
- 字幕缓存准备与渲染共用通道，避免同源字幕与词轴同时写入；完成素材准备即释放通道，导演 AI 可并行。
- 已选片单通过函数参数传入，不再在正式渲染中替换全局 AI 函数。滤镜预设也通过参数传入。
- 保留按任务绑定的日志与费用上下文、按预览 ID 存储的片单、独立停止事件及导演工作目录。

## 验证边界

自动化测试使用模拟分析和渲染，未产生付费 AI 调用。已检查前端脚本和 Python 语法。真实两路任务的内容质量、成片和运行时间仍需用户验收。
