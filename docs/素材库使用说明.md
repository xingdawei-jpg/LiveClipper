# 素材库 使用说明

素材库解决一个问题：**某句话是哪个主播、在哪场直播的第几秒说的。**

你输入一个关键词或一整句话，它会把所有说过的视频列出来，带主播、视频文件名、精确时间点和上下文。整理话术、找素材、核对口播、跨主播抄爆款话术，都靠它。

---

## 一、先理解一个关键前提

**搜索只查索引，不读素材目录。**

| | 作用 | 搜索时会读吗 |
|---|---|---|
| **素材目录**（你硬盘上的文件夹） | 存放视频文件；只在「建立索引」和「打开视频」时用到 | ❌ 不读 |
| **索引**（一个数据库文件） | 存字幕文案 + 时间点 + 视频文件名 + 主播 | ✅ **只读它** |
| **检索结果** | 告诉你是哪个主播的哪个视频、第几秒 | — |

所以：

- **没有视频文件也能搜。** 别人把索引发给你，你导入后直接就能搜出"哪个视频有这句话"，不需要先下载视频。
- **换素材目录不会换索引。** 输入框里那个目录只是"下次建索引时扫哪里"，不会清空已有索引。

---

## 二、一个素材目录 = 一个索引

这是素材库最核心的设计。你每扫描一个目录，就得到**一个独立的索引**，它们互不影响：

```
索引列表
├─ 录屏        本机  103 视频 · 17634 句 · 19.6h
├─ jccc        本机  181 视频 · 38669 句 · 46.1h
├─ Ayobe小贤   本机   96 视频 · 11160 句 · 18.3h
└─ 影子_10月   导入   69 视频 · 11353 句 · 19.1h   ← 同事发来的
```

每个索引都可以**单独重建、单独导出、单独删除**：

| 按钮 | 作用 |
|---|---|
| **重建** | 清掉这个索引的内容，重新扫描它的素材目录（不动其他索引） |
| **导出** | 只把这一个索引导出成 zip，发给同事 |
| **删除** | 删掉这个索引的索引内容（**不会删你的视频文件**） |

---

## 三、建立索引

1. 在「素材目录」里填或选你的录屏根目录（例如 `E:\切片\录屏`，下面按主播分文件夹）；
2. 勾选 **包含子文件夹**（视频在主播子目录里时必须勾）；
3. 决定要不要勾 **缺字幕自动语音识别**（见下方提醒）；
4. 点「**建立/更新这个目录的索引**」。

### 建议先点「试扫目录」

它会告诉你这次扫描的真实工作量，避免白等：

```
试扫完成：视频 515 个（已在索引 199 个 · 本次可新增 316 个）
  · 已有字幕 200 个 · 待识别 315 个 · 151.2 GB
  → 点「建立/更新索引」只处理新增的 316 个，已有的跳过。
```

而且**点「建立/更新这个目录的索引」时也会自动先试扫一次**：

- 如果这个目录已经全部索引过，它会直接告诉你"无需重跑"并停止；
- 如果要新增的视频里有较多缺字幕的、而你又勾了自动识别，它会**先弹确认框**说明要跑多少个、可能很慢，让你决定是否继续。

- **已在索引里的会被跳过**，重复扫描不会重复入库；
- 如果整个目录都已索引过，它会直接告诉你"无需重跑"。

### 关于「缺字幕自动语音识别」

- **勾上**：没有字幕的视频会调语音识别补字幕，**能搜到的视频更多，但很慢**（几百个视频可能跑很久）；
- **不勾**：只索引已有字幕的视频，**快**（几分钟级别）。

建议：想先快速用起来就**先不勾**，把有字幕的部分索引好；之后有空再勾上补剩下的。

## 四、搜索

### 基本用法

搜索框里输入关键词或**一整句话**，点「检索」：

| 匹配方式 | 实际行为 | 什么时候用 |
|---|---|---|
| **智能（先整句，再分词）** | 先按整句精确匹配；找不到就把输入按**空格/逗号/顿号**拆成几个词，要求这些词出现在**同一句**里 | 默认，多数情况 |
| **整句精确** | 严格按你输入的连续文字匹配 | 确定原话就是这个连续片段 |
| **分词匹配（空格分隔多个词）** | 用空格分隔的多个词，要求**同一句里都出现**（不要求相邻） | 记得几个词但顺序/说法不确定 |

「上下文」控制每处命中前后带几句，默认前后 2 句，足够看清说的是什么。

### 搜一整句话搜不到？这是正常的

**库里的一句话，是字幕按停顿切出来的，不一定等于你记忆里的那一句。**

实测例子：库里有 102 处说过"这个帽子"，但没有一处是连续的"帽子版型"：

```
这个帽子版型很显瘦   ->  0 命中        ← 你记忆里的一整句
这个帽子             ->  102 命中      ← 缩短到确定说过的片段
帽子 版型（分词模式） ->  25 命中      ← 两个词在同一句里出现过
```

所以：

- **搜不到整句时，缩短到最有特点的那几个字**（一般 2~4 个字最好用）；
- 或者改用「**分词匹配**」，用空格把关键词拆开，例如 `帽子 版型`——它只要求同句出现，不要求相邻，命中面更广；
- 注意「智能」模式的拆分是**按空格/标点**，不是中文分词，所以 `这个帽子版型很显瘦` 这种连续输入不会被自动拆开，只会整句匹配一次。

### 搜索范围：只搜某一个索引

搜索框上方的「**搜索范围**」是个下拉：

```
搜索范围  [全部索引（389 视频 / 70590 句） ▾]
           ├─ 全部索引
           ├─ 录屏
           ├─ jccc
           └─ Ayobe小贤
```

点其中一个，就**只在这个索引里搜**（右侧索引列表里那项会同时高亮）。再点「全部索引」恢复。

**为什么要选范围**：导入的索引多了以后，一次搜全部会很慢、结果也杂。只想看某个主播/某个批次，就限定过去。

### 结果怎么看

一张卡片 = 一个视频：

```
影子 待确认_20260930_172358_01_1.mp4   录屏        命中 6 处  首次出现 10:06
E:\切片\录屏\影子\待确认_20260930_172358_01_1.mp4
┌───────────────────────────────────────────────┐
│ 10:06  ▶ 打开视频  📁 打开视频地址  ⧉ 复制时间点  │
│  10:02  你别说他拍的还不看，                     │
│  10:04  他说可喜欢这一点了，                     │
│  10:06  因为显瘦 颜值可高。          ← 命中句加粗  │
│  10:07  因为显瘦 它不显胖。对，这衣服它是显瘦。   │
└───────────────────────────────────────────────┘
```

卡片上的按钮：

| 按钮 | 作用 |
|---|---|
| **▶ 打开视频** | 用系统默认播放器打开该视频（时间点已可一键复制，手动跳过去） |
| **📁 打开视频地址** | 在资源管理器里打开该视频所在文件夹并选中它 |
| **⧉ 复制时间点** | 复制这个时间点 |
| **复制全部时间点**（结果区右上） | 一次性复制所有命中的时间点，方便整理 |

卡片上的标记：

- **`录屏`** 这样的徽标 = 这条记录来自哪个索引；
- **`需下载`** = 本机没有这个视频文件（多半是导入的索引），**拿卡片上的文件名去网盘查找下载**。

### 两种筛选的分工

| 位置 | 作用 | 时机 |
|---|---|---|
| 搜索框上方「**搜索范围**」 | 选**索引**，决定"搜哪些数据" | 搜索**前** |
| 结果区右侧「**按主播筛选**」 | 选**主播**，在已有结果里再缩小 | 搜索**后** |

右侧还有「只看某个视频」和「热门文案」（列出这个主播说过最多的口播句，双击直接检索）。

## 五、分享索引给同事

素材库最实用的地方：**索引可以像文件一样传给别人，别人不用有视频就能搜。**

### 导出方

1. 点右侧索引卡片上的「**导出**」（只导这一个），或面板头部的「**导出选中**」（弹窗选维度）；
2. 弹窗里选维度：**按索引**（推荐）/ 按主播 / 按目录；
3. 选保存位置 → 得到一个几 MB 的 zip。

一个 103 视频 / 17634 句的索引，导出来大约 **5 MB**、**2 秒**左右。

### 接收方

1. 点页头「**导入索引**」，选那个 zip（**可多选**，比如不同主播各一个）；
2. 导入后它会作为一个**独立索引**出现在列表里（类型标「导入」）；
3. 直接搜就行——**不需要本机有视频文件**。

导入完成后**不用刷新页面**，列表会在几秒内自动更新。

### 边界，先说清楚

- **包里不含视频文件**，只有文案索引和时间点；
- 接收方看到「需下载」的视频，要**自己拿文件名去网盘找**；
- **索引 = 该主播全部口播文案 + 时间点**，等于话术库，**发给谁需要你把关**；
- 导入的索引**不能重建**（本机没有源素材目录），需要更新就让分享的人重新导出一份。

## 六、常见问题

**搜不到我确定说过的话？**

按顺序排查：

1. **这个视频进索引了吗**——点「试扫目录」，看"已在索引 N 个"是否符合预期；
2. **它有没有字幕**——没有字幕的视频，除非勾了"缺字幕自动语音识别"，否则不会入库；
3. **搜索范围是不是限定了**——看搜索框上方是不是还停在某个索引上，点「全部索引」；
4. **是不是按整句搜的**——库里的句子是按停顿切的，你记忆里的整句话可能对不上，改搜其中 2~4 个字的片段，或用「分词匹配」把词拆开；
5. **换素材目录后忘了建索引**——换了目录要点「建立/更新这个目录的索引」，不会自动扫。

**导入后列表里没出现新索引？**

等 2~5 秒（界面每 2.5 秒自动同步一次）。如果一直没有，看页面下方「素材库日志」里的报错。

**点了导出报 `Method Not Allowed`？**

说明前端文件是旧版。**刷新页面**（Ctrl+F5）即可。

**改了设置/代码要重启还是刷新？**

- 只改了界面（HTML/CSS/JS）：**刷新页面**；
- 改了后端逻辑或接口：**重启工具**。

**索引文件在哪？**

```
%APPDATA%\LiveClipper\material_library\material.sqlite3
```

所有索引都在这一个数据库文件里（右上角「打开」可直接跳到），不同素材目录的索引靠归属区分，不是多个文件。

导出到用户数据目录的包在：

```
%APPDATA%\LiveClipper\material_exports\
```

**删除索引会删视频吗？**

不会。在索引卡片上点「删除」，只删这个索引的内容（文案、时间点、索引条目），**视频文件和字幕文件都不动**。删除只影响这一个索引，其他索引不受影响。

## 七、推荐使用流程

**第一次用（自己建）**

1. 选素材目录 → 点「试扫目录」看清工作量；
2. **先不勾**"缺字幕自动语音识别" → 点「建立索引」，几分钟就能用；
3. 搜一个你确定说过的词，验证能搜到；
4. 有空再勾上自动识别，重跑一次补全缺字幕的视频。

**团队协作（共享）**

1. 一人负责建索引（素材最全的那台机器）；
2. 按主播或按批次**分别导出**索引包（一个包一个主播，接收方按需下载）；
3. 通过网盘/微信把 zip 发给同事；
4. 同事「导入索引」→ 直接搜 → 命中后按文件名去网盘下载对应视频。

---

## 八、能力边界（如实说明）

- **只索引索引过的内容**：没入库的视频搜不到；小于 **512KB** 的文件会被跳过（碎片/占位文件）；
- **匹配是文字匹配**：整句 / 分词 / 任意长度子串（单字也能搜，实测"瘦"命中 735 处，但结果太泛，建议 2~4 个字）；
- **不做语义搜索**：是文字匹配，不会"理解了意思再找"；同义说法（显瘦 vs 显身材）互相搜不到；
- **句子按停顿切分**：你记忆里的一整句可能跨库里的多句，整句搜不到时缩短关键词（见第四节）；
- **上下文来自字幕**：字幕识别有误时，展示的文本也会有误；
- **「打开视频」不自动跳时间点**：用系统默认播放器打开，时间点需要手动跳（已提供一键复制）。
