# AELE 商品归属与时长真实性修复

## 修复范围

- 自动模式优先使用当前实际分析素材的明确商品标题；批量列表中其他 SKU 不再污染单条预览。
- Director 在原片时间顺序中声明换品范围；程序用连续、明确的商品名口播交叉核对。
- 已确认的其他商品讲解范围在进入 Beat Casting 前从可执行池排除。程序不替 AI 选择或添加句子。
- 主方案、AI 备选及左侧完整候选只保留当前主商品范围；明确的同句搭配仍可保留。
- 重复字幕 ID 不再增加“有效内容时长”。报告同时显示播放时长、不重复内容时长和重复秒数。
- 工作台增加片段 occurrence identity：同一源句即使出现多次，也不会在保存/恢复时被静默合并、移到最后或串用逐词编辑。
