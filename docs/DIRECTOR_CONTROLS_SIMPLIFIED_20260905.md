# AI 导演参数精简收口 · 2026-09-05

## 范围

智能成片与混剪同步。只收敛参数界面与传参合同，不重构 AI 导演，不增加 AI 调用，不修改逐句/逐词编辑、已选顺序或 M3。

## 页面

- 常用：商品类型（留空自动识别）、一个导演侧重、四项内容取舍。
- 服饰侧重：AI 自动推荐 / 上身效果 / 穿着体验 / 搭配场景 / 面料工艺。其他品类使用效果、体验、场景、品质四个通用方向。
- 内容取舍：价格促销、库存催单、尺码讲解支持跟随全局设置 / 排除 / 仅正文 / 允许；跟随项显示当前实际状态。其他商品搭配为允许作搭配 / 排除。
- 更多设置：具体商品名称或款号、二级类目、300 字补充要求、现有预设保存/删除。
- 商品名优先于类型，并在折叠状态显示锁定信息；有补充要求时也显示提示。

## 数据与旧参数

- `director-controls-v2` 由同一个收集函数进入智能、混剪、直接批量成片与预览。备选方案重跑延续任务参数。
- 移除开头/收尾偏好、卖点多选、关键词多选和旧权重叠加。前端不发送，服务端收到旧混合字段也清理；AI 自动安排开头和收尾。
- 旧预设及页面偏好仍可读：能对应的方向映射到单选；旧避选迁移为可见内容取舍；旧重点词移到可编辑补充要求。迁移提示明确说明已取消的偏好不再生效。
- 新预设与页面偏好只保存新字段，不再保存旧卖点勾选。
- 任务级允许能覆盖对应全局种类的禁用，但不改全局设置、不删除自定义禁用词；其他种类规则保持原状。
- “其他商品搭配=排除”同时进入两遍 Prompt 和现有商品关系校验。程序报告关系冲突，不自动删改 AI 语义选择。
