# Selection Code Map

| Module | File | Key functions/classes | Responsibility | Input -> output | Decides retention? | Calls AI? | Audit risk |
|---|---|---|---|---|---|---|---|
| API tasks | `web_client/server.py` | payload models; `_run_smart_preview`, `_run_smart_cut`, `_run_mix_preview`, `_run_mix` | Starts independent preview/direct tasks | UI payload -> worker | Indirect | No | Different task routes must preserve their own inputs |
| Preview finalization | `web_client/server.py` | `_preview_segment_selection_units`, `_merge_selected_segments`, `_hard_filter_preview_selection`, `_sync_preview_final_selection_metadata` | Turns UI rows/word choices into renderable clips/manifest | preview JSON -> tuples/manifest | Yes | No | UI-selected text may disappear in standalone/hard filter conversion |
| Main render orchestration | `app/cutter_logic.py` | `process_video`, `process_video_mix` | ASR/cache, calls selection, cutting/rendering | media/SRT/settings -> output/run log | Indirect | No | Final record schema differs from preview schema |
| Local ASR | `app/local_asr.py`, `app/local_asr_chunking.py`, `app/local_asr_quality.py`, `app/local_asr_review.py` | SenseVoice alignment/chunk/quality helpers | Produces local text, punctuation, word timing and semantic boundaries | audio -> SRT/words | Upstream | No | Text/timing quality constrains all later recall |
| Cloud ASR | `app/volcengine_asr.py`, `app/aliyun_asr.py` | provider adapters | Produces provider SRT/word data | audio -> SRT/words | Upstream | No | Provider path changes candidate source quality |
| Candidate quality | `app/candidate_quality.py` | `filter_candidate_clips`, `leading_fragment_trim` | Removes obvious ASR/fragment candidates | tuples -> filtered tuples | Yes | No | Exclusions before Director are not persisted per ID |
| Freeze/context | `app/ai_clipper.py`, `app/selection_context.py`, `app/selection_contracts.py` | `_freeze_director_candidates`, `SelectionCandidate`, `CandidateSet`, `build_selection_context` | Merges incomplete adjacent text and creates candidate contract/story groups | SRT -> immutable candidates | Yes; alters boundaries | No | Merge/trim is irreversible for the task |
| Policies/safety | `app/content_policy.py`, `app/selection_safety.py`, `app/ai_clipper.py` | `_filter_price_and_cta`, live/size/subject/product filters | Applies policy and product eligibility | candidates + policy -> safe IDs | Yes | No | Policy is passed in several paths; preview hard recheck currently calls without explicit task policy |
| Category/profile | `app/category_profiles.py`, `app/ai_clipper.py` | category detection/overlays/exact subject filters | Establishes product/category constraints | controls/text/file hints -> category rules | Yes | No | Text cannot reliably resolve visual item changes |
| Content Review | `app/content_review.py` | `ContentCard`, `HookPackage`, `review_candidates`, `repair_hook_pairs` | LLM content cards, tiers, HookPackage evidence | safe inventory -> review bundle/cache | Yes in `on` | Yes | Cache retains cards but not original full request inventory |
| Marketing Intent | `app/marketing_intent.py` | `MarketingIntentBundle`, `marketing_intent_prompt_contract` | Optional intent/arcs schema | review response -> intent metadata | No direct current `on` control | No standalone call | In current code it is requested only for `shadow` review |
| Director | `app/ai_clipper.py` | `ai_analyze_clips`, `_call_ai`, prompt contracts, parse/normalize helpers | Selects and orders supplied IDs | eligible indexed transcript -> playlist | Yes | Yes | Cannot recover missing upstream candidates |
| Duration/source mix | `app/ai_clipper.py` | duration contract helpers, `_call_director_incremental_fill`, `_call_director_trim_selection`, source quota helpers | Fills/trims to duration and source contract | playlist + eligible inventory -> adjusted playlist | Yes | Sometimes | Local and AI branches can change final selection after initial Director output |
| Final audit | `app/ai_clipper.py`, `app/content_review.py` | `_director_hard_audit`, `audit_final_sequence`, `review_final_sequence` | Checks hard safety/structure and optional LLM review | playlist -> pass/flag/review | Yes for hard audit | Branch dependent | Legacy whole-playlist rewrite prompt exists; current call sites determine reachability |
| History/dedup | `app/ai_clipper.py` | `_filter_recent_similar_clips`, semantic similarity helpers | Avoids similar previous output when quality allows | candidates/history -> filtered/ranked set | Potentially | No | History is another pre-Director narrowing path |
| Visual postprocess | `app/smart_crop.py`, `app/vision_replace.py`, `app/cutter_logic.py`, `web_client/server.py` | crop/Ken Burns/vision replacement/visual fingerprint | Post-selection visual transforms or whole-file duplicate comparison | selected clips/media -> rendered media | Not Director selection | Separate vision call possible after selection | Visual features do not enter Director’s candidate table |
